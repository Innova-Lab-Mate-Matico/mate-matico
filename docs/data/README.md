# 📊 Módulo de Ingeniería y Auditoría de Datos

Este directorio centraliza los artefactos técnicos, scripts y reportes analíticos correspondientes a la auditoría de integridad y comportamiento operativo de la plataforma.

## Contenido de la Sección:
* **Pipeline ETL & Extracción:** Automatización desarrollada en Python para la ingesta de datos desde Firebase.
* **Procesamiento y Almacenamiento:** Modelado, vistas limpias y validaciones ejecutadas en SQL Server.
* **Análisis Estadístico:** Informes ejecutivos y visualizaciones avanzadas desarrolladas para la medición de retención, rachas (*streaks*) y rendimiento.
